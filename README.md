# rd2diff 

Implements the method developed in Graetz & Nordin (2026): A Double-differences Approach to Inference in Regression Discontinuity Designs with a Discrete Running Variable.

The file ```rd2diff.do``` contains the Stata command. The file ```rd2diff-examples.do``` contains examples illustrating the use of the command, using synthetic data.

The file ```rd2diff.R``` contains the R functions. The two functions ```rd2diff``` and ```rd2diff.aggregate``` implement the estimation procedure. The file ```rd2diff-examples.R``` contains examples illustrating the use of these two functions, using synthetic data.

Note that function implementation is at an early stage and subject to change.
